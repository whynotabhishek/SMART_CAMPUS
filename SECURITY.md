# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within CampusFind, please send an e-mail to security@campusfind.local. All security vulnerabilities will be promptly addressed.

## Security Features
- Strict CSP headers
- Rate Limiting on API endpoints
- JWT-based API Authentication (Supabase)
- Sanitized Inputs
- No sensitive keys in source control
